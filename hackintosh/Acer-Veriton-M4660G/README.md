# Hackintosh for Acer Veriton M4660G Desktop PC
Somewhat successful OpenCore hackintosh project for my pc

## Download
Download OC folder: \[[ OC.zip ](http://onedev135.github.io/files/hackintosh/Acer-Veriton-M4660G/OC.zip)\]

## Specs

* CPU: Intel Core i7-8700 3.20GHz
* iGPU: Intel UHD Graphics 630 (512MB pre-allocated memory)
* dGPU: No
* RAM: 16GB DDR4
* OS: macOS Sequoia 15.3
* SMBIOS: iMac19,1
* Boot Manager: OpenCore 1.0.3 RELEASE
